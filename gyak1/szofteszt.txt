1. DiscountCalculator

================================================================================



1. Hibás kódrészlet:

--------------------

// Határérték hibák:

if (orderValue > 10000 && orderValue < 25000) {

} else if (orderValue >= 25000 && orderValue <= 50000) {

} else if (orderValue > 50000) {



// VIP kedvezmény hozzáadása:

if (isVip === true) {

    discount += 5;

}



// Fizetendő összeget számító képlet és hiányzó validáció:

return orderValue - discount;



2. A hiba magyarázata:

----------------------

- Határértékek kezelése: 

  * "orderValue > 10000": Pontosan 10 000 Ft-os rendelésnél nem ad kedvezményt a specifikációban előírt 5% helyett.

  * "<= 50000" és "> 50000": Pontosan 50 000 Ft-nál 10% kedvezményt ad a specifikációban szereplő 15% helyett.

- VIP kedvezmény: A "discount += 5" utasítás 500%-os kedvezményt ad a 0.05 (5 százalékpont) helyett.

- Végső ár kiszámítása: Az "orderValue - discount" kifejezés a kedvezmény kulcsértékét (pl. 0.05) vonja ki az árból a kedvezmény konkrét összege (orderValue * discount) helyett.

- Negatív érték validációja: Nincs ellenőrizve a negatív rendelési érték, amit a specifikáció kifejezetten tilt.



3. A helyes működés és a javítás módja:

---------------------------------------

function calculateDiscountedPrice(orderValue, isVip) {

    if (orderValue < 0) {

        throw new Error("Negatív rendelési érték nem megengedett.");

    }



    let discount = 0;

    if (orderValue >= 50000) {

        discount = 0.15;

    } else if (orderValue >= 25000) {

        discount = 0.10;

    } else if (orderValue >= 10000) {

        discount = 0.05;

    }



    if (isVip) {

        discount += 0.05;

    }



    if (discount > 0.20) {

        discount = 0.20;

    }



    return orderValue * (1 - discount);

}

2. ParkingFeeCalculator

================================================================================



1. Hibás kódrészlet:

--------------------

// Megkezdett órák és ingyenes időszak kezelése:

if (minutes < 15) return 0;

let hours = Math.floor(minutes / 60);



// VIP kedvezmény levonása:

if (isVip) {

    fee = fee - 20;

}



// Maximális díj korlátozásának helye:

if (fee > 5000) {

    fee = 5000;

}



2. A hiba magyarázata:

----------------------

- Megkezdett órák számítása: A "Math.floor()" lefelé kerekít. Pl. 30 perc parkolásnál "30 / 60 = 0" órát számol, így a megkezdett óra díja elvész. Helyette "Math.ceil()" (felfelé kerekítés) szükséges.

- Ingyenes időszak és validáció: A "minutes < 15" miatt pontosan 15 perc esetén már fizettetne a kód. A negatív percekre sem dob hibát.

- VIP kedvezmény: A "fee - 20" kifejezés 20 Ft-ot von le a 20%-os kedvezmény ("fee * 0.8") helyett.

- Napi maximális díj: A 5000 Ft-os korlátot a kedvezmények kiszámítása ELŐTT kell az alapdíjra alkalmazni, különben hosszabb parkolás esetén a hétvégi és VIP kedvezmények nem a napi maximumból vonódnak le.



3. A helyes működés és a javítás módja:

---------------------------------------

function calculateParkingFee(minutes, isWeekend, isVip) {

    if (minutes < 0) {

        throw new Error("Negatív parkolási idő nem megengedett.");

    }



    if (minutes <= 15) {

        return 0;

    }



    let hours = Math.ceil(minutes / 60);

    let fee = hours * 600;



    if (fee > 5000) {

        fee = 5000;

    }



    if (isWeekend) {

        fee = fee * 0.5;

    }



    if (isVip) {

        fee = fee * 0.8;

    }



    return fee;

}

3. CinemaTicketCalculator

================================================================================



1. Hibás kódrészlet:

--------------------

// Életkor határok és validáció hiánya:

if (age <= 6) {

} else if (age > 65) {



// Kedvezmények halmozása:

if (isStudent) {

    price = price * 0.8;

}



// 3D felár kiszámítása:

if (is3D) {

    price = price * 1.8;

}



2. A hiba magyarázata:

----------------------

- Életkori határok & validáció:

  * "age <= 6": A 6 éves gyermeket is ingyenes kategóriába sorolja a 30%-os kedvezmény helyett ("age < 6" kell).

  * "age > 65": A 65 éves látogató kimarad a 40%-os kedvezményből ("age >= 65" kell).

  * Hiányzik a negatív és 120 év feletti életkor ellenőrzése.

- Kedvezmények halmozása: A kód egymás után szorozza a kedvezményeket (pl. életkor + diák), míg a specifikáció szerint csak a legnagyobb kedvezmény alkalmazható.

- 3D felár: A "price * 1.8" kifejezés 80%-kal növeli meg a kedvezményes jegyárat ahelyett, hogy fix 800 Ft-ot adna hozzá, és a felárra is tévesen kedvezményt ad.



3. A helyes működés és a javítás módja:

---------------------------------------

function calculateTicketPrice(age, isStudent, is3D) {

    if (age < 0 || age > 120) {

        throw new Error("Érvénytelen életkor.");

    }



    let basePrice = 3000;

    let maxDiscount = 0;



    if (age < 6) {

        maxDiscount = 1.0; // 100% kedvezmény (ingyenes)

    } else {

        if (age < 18) {

            maxDiscount = Math.max(maxDiscount, 0.30);

        }

        if (age >= 65) {

            maxDiscount = Math.max(maxDiscount, 0.40);

        }

        if (isStudent) {

            maxDiscount = Math.max(maxDiscount, 0.20);

        }

    }



    let ticketPrice = basePrice * (1 - maxDiscount);



    if (is3D) {

        ticketPrice += 800;

    }



    return ticketPrice;

}

4. ExamGradeCalculator

================================================================================



1. Hibás kódrészlet:

--------------------

// Minimum pontszámok feltételének logikája:

if (theory < 30 && practice < 20) {

    return 1;

}



// Jegyszerzési pont határok:

} else if (total <= 60) {

    return 2;

} else if (total <= 70) {

    return 3;

} else if (total <= 85) {

    return 4;

}



2. A hiba magyarázata:

----------------------

- Hiányzó input validáció: Nincs ellenőrizve, hogy az elmélet 0–60, a gyakorlat pedig 0–40 pont közé esik-e.

- Logikai és/vagy hiba: A "theory < 30 && practice < 20" feltétel miatt a vizsga csak akkor bukik el automatikusan, ha MINDKÉT részvizsga eléri a bukási határt. Ha az elmélet pl. 10 pont, de a gyakorlat 30, a kód átengedi a hallgatót. Helyette "||" (vagy) kapcsolat kell.

- Osztályzási határok:

  * "total <= 60" esetén 2-est ad, miközben a 60 pont már 3-ast ér.

  * "total <= 70" esetén 3-ast ad, miközben a 70 pont már 4-est ér.

  * "total <= 85" esetén 4-est ad, miközben a 85 pont már 5-öst ér.



3. A helyes működés és a javítás módja:

---------------------------------------

function calculateGrade(theory, practice) {

    if (theory < 0 || theory > 60 || practice < 0 || practice > 40) {

        throw new Error("Érvénytelen pontszám.");

    }



    if (theory < 30 || practice < 20) {

        return 1;

    }



    let total = theory + practice;



    if (total < 50) {

        return 1;

    } else if (total < 60) {

        return 2;

    } else if (total < 70) {

        return 3;

    } else if (total < 85) {

        return 4;

    } else {

        return 5;

    }

}

5. PackageClassifier

================================================================================



1. Hibás kódrészlet:

--------------------

// Small kategória szigorú egyenlőtlenségei:

if (weight < 2 && length < 30 && width < 30 && height < 30) {



// Medium kategória logikai kapcsolata:

if (weight <= 10 && (length <= 60 || width <= 60 || height <= 60)) {



// Érvénytelen adatok ellenőrzésének hiánya.



2. A hiba magyarázata:

----------------------

- Hiányzó validáció: Nem ellenőrzi, hogy a méretek vagy a tömeg 0 vagy negatív értékűek-e (ez esetben "INVALID"-ot kellene visszaadnia).

- Small határértékek: A "< 2" és "< 30" feltételek kizárják a pontosan 2 kg-os vagy 30 cm-es csomagokat ("legfeljebb" esetén "<=" szükséges).

- Medium logikai operátor: A "(length <= 60 || width <= 60 || height <= 60)" kifejezésben "||" (vagy) szerepel. Így egy 1000 cm × 10 cm × 10 cm-es csomagot is MEDIUM-nak sorolna be. Specifikáció szerint mindhárom méretnek "<= 60"-nak kell lennie ("&&" kapcsolat).



3. A helyes működés és a javítás módja:

---------------------------------------

function classifyPackage(weight, length, width, height) {

    if (weight <= 0 || length <= 0 || width <= 0 || height <= 0) {

        return "INVALID";

    }



    if (weight <= 2 && length <= 30 && width <= 30 && height <= 30) {

        return "SMALL";

    }



    if (weight <= 10 && length <= 60 && width <= 60 && height <= 60) {

        return "MEDIUM";

    }



    if (weight <= 30 && length <= 120 && width <= 120 && height <= 120) {

        return "LARGE";

    }



    return "OVERSIZE";

}
