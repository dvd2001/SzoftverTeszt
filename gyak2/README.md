# Arab szám → Római szám konverter (TDD)

Ez a projekt egy JavaScript nyelven írt konverter, amely arab számokat (1–3999) alakít át római számokká a Test Driven Development (TDD) módszertant követve.

## Projekt struktúra

- `function.js`: A konverziós logikát megvalósító függvény.
- `test.js`: QUnit tesztesetek (határesetek, érvénytelen bemenetek, összetett római számok).
- `test.html`: Böngészőben futtatható QUnit tesztfelület.
